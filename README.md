# КомСтрой74 — Сайт строительной компании

Профессиональный сайт для компании по ремонту коммерческих помещений в Челябинске.

## Технологии

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Google Fonts** — Montserrat + Inter

## Секции сайта

1. **Header** — фиксированная шапка с навигацией и кнопкой CTA
2. **Hero** — главный экран с фоновым изображением, заголовком и статистикой
3. **Services** — 6 видов коммерческих объектов с карточками
4. **WhyUs** — преимущества компании и цифры
5. **Process** — 6 этапов работы
6. **Portfolio** — галерея проектов с фильтрацией
7. **Testimonials** — отзывы клиентов
8. **Contact** — форма заявки и контактные данные
9. **Footer** — ссылки, соцсети, реквизиты

## Запуск

```bash
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000)

## Дизайн

Разработано с использованием принципов **UI UX Pro Max**:
- Стиль: Trust & Authority (строительный B2B)
- Палитра: Dark Navy + Orange (#f97316)
- Типографика: Montserrat (заголовки) + Inter (текст)
