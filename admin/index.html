Публикация фото

Для фотографий используйте любой из способов:

Google Drive: Файл → Поделиться → Все, у кого есть ссылка → Скопировать ссылку. Вставьте ссылку в поле «Фото» — система автоматически преобразует её.

imgbb.com: Загрузите фото → Скопируйте «Direct link».

Любой URL: Прямая ссылка на JPG/PNG.
