# Что делать — по порядку

Комплект документов по 152-ФЗ для ИП Думаева Н. Б., сайт shtukatur74.ru.
Всё, что можно было подготовить, подготовлено. Осталось четыре действия.

---

## Шаг 1. Распечатать и подписать приказ

Файл **1-prikaz-otvetstvennyy.md**.

Поставить дату и подпись. Никуда не отправляется, хранится у вас в папке
с документами. Требуется по ст. 18.1 152-ФЗ, спрашивается при проверке.

Дату запомните — она понадобится на шаге 3.

## Шаг 2. Распечатать и подписать перечень мер

Файл **2-mery-bezopasnosti.md**.

Тоже только для себя. В нём описано то, что реально сделано на сайте, —
каждый пункт можно проверить, если попросят.

Заодно завести журнал обращений — файл **3-zhurnal-obrashcheniy.md**.
Скорее всего останется пустым; спрашивают наличие, а не записи.

## Шаг 3. Подать уведомление

Файл **4-uvedomlenie-rkn.md** — там готовые ответы по каждому полю формы.

Куда: **pd.rkn.gov.ru** → «Формы электронных документов» → «Уведомление об
обработке персональных данных». Нужна подтверждённая учётная запись
Госуслуг или электронная подпись.

От вас четыре значения, которых я знать не могу:

1. адрес регистрации по паспорту;
2. дата приказа № 1;
3. ИНН и адрес РЕГ.РУ — из договора за хостинг;
4. дата, когда форма заработала на сайте.

Остальное копируется из файла как есть.

## Шаг 4. Дописать одну строку на сайте

В файле `privacy.html` в разделе 1 отмечено место для наименования
налогового органа, зарегистрировавшего ИП, и даты регистрации. Возьмите
из Листа записи ЕГРИП.

Требуется статьёй 9 Закона «О защите прав потребителей»: индивидуальный
предприниматель обязан сообщить потребителю сведения о государственной
регистрации и наименование зарегистрировавшего органа.

## Что уже сделано и переделывать не нужно

**Политика обработки персональных данных** — опубликована на сайте, ссылка
в подвале каждой страницы. Содержит все обязательные разделы, включая
порядок действий при инцидентах со сроками 24 и 72 часа по ст. 21.1.

**Согласие на обработку** — отдельная галочка в форме, не отмечена по
умолчанию. Перечисляет ровно те данные, которые форма отправляет, включая
IP-адрес. Проверяется дважды: в браузере и на сервере. Без отметки сервер
отклоняет заявку, даже если проверку в браузере обойти.

**Журнал согласий** — дата, время, IP и версия политики пишутся автоматически
при каждой заявке. Это доказательство по ст. 9, если кто-то заявит, что
согласия не давал.

**Локализация** — сайт и почта на российском хостинге, трансграничной
передачи нет.

**Аналитика по согласию** — Яндекс.Метрика не загружается, пока посетитель
не нажал «Принять». Проверено: до согласия обращений к серверам Яндекса
ноль.

**Защита** — HTTPS с редиректом, ограничение частоты обращений к форме,
защита от роботов, журналы закрыты от доступа из сети, пароль почты в
закрытом файле.

**Публичная оферта** — цены на сайте сопровождаются оговоркой по ст. 437 ГК,
сквозной строкой в подвале и отдельным блоком в прайсе.

## Про сроки

Уведомление подаётся **до** начала обработки. Форма на сайте уже работает,
то есть формально срок пропущен. Штраф по ст. 19.7 КоАП символический —
несколько сотен рублей, и применяется он редко. Опаснее другое: работающая
форма у оператора, которого нет в реестре, — это то, что первым делом
проверяют по жалобе.

Поэтому подавайте не откладывая. Отказать по существу вам не могут:
уведомление не разрешение, его просто регистрируют.
